# Contributing to the "Events Glossary"


The glossary is intended to be limited to terms whose usage can be verified in literature, blog posts, and talks on the topics of Event-Driven Architecture and Event Sourcing. 

Therefore, all contributions and proposed changes must be supported by a source reference. The source should be provided as a footnote, and the definition should reference it.

The curator of the glossary reserves the right to reject sources and resulting definitions if they deem them insufficiently helpful.

If you would like to make a suggestion under these conditions, please do so either via an [issue](https://github.com/lutzh/events-glossary/issues) or a [pull request](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/).


Thank you very much!
